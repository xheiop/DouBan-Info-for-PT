# Douban-Info-for-PT

为国外 PT（Private Tracker）站点补充豆瓣 / TMDB 中文信息的用户脚本。在**不改动站点原有内容**的前提下，就地补上**中文片名**、**中文剧情简介**、**豆瓣评分**与**豆瓣入口按钮**，覆盖**种子详情页**、**种子列表页**，以及 PTP 的 **Top 10 榜单页**与浏览页。

数据以**豆瓣优先**，豆瓣缺失的片名、简介、海报可由 **TMDB 兜底**补齐；请求走本地队列限流 + 30 天缓存，只读取当前页面列出的资源，不预取其它页面。目前适配 **21 个站点**。

**主要功能**
- **中文片名**：详情页跟在原片名旁，列表页加在原标题下方；点击跳豆瓣条目（中文片名由 TMDB 补上时跳 TMDB）。片名与年份排版按电影 / 剧集单集 / 整季区分。
- **中文简介**：替换或补充站点原英文简介，鼠标悬停可看原文；无中文简介时保留站点原文。
- **豆瓣评分**：复用站点自身的评分徽章 / 星级样式，点击跳豆瓣条目。
- **豆瓣入口按钮**：加在站点外链按钮（TMDB / IMDb 那一排）里，样式与相邻按钮一致。
- **种子列表页**：每个资源补中文片名，光标停在原标题或中文片名上弹出豆瓣简介面板（海报 + 评分 + 中文片名 + 简介 + 类型标签）。
- **PTP Top 10 / 浏览页**：Top 10 / Top 100 / Top 250 与 `torrents.php` 浏览页的四种视图统一处理。
- **豆瓣卡片站点**：Aither / AvistaZ / KG / PHD / SC / TGX / TorrentLeech 用统一的豆瓣信息卡片。
- **TMDB 兜底**：豆瓣缺中文片名 / 简介 / 海报时按优先级从 TMDB 补齐。

### 详情页：中文片名 / 简介 / 评分 / 入口按钮

中文片名跟在站点原片名旁（个别站插在片名与年份之间），点击跳豆瓣条目；中文简介替换或补充在原英文简介处；豆瓣评分复用站点自身评分徽章样式；豆瓣入口按钮加在 TMDB / IMDb 外链按钮行里。条目没有豆瓣数据时，片名与简介保持站点原文。

- **BTN**：标题行中文片名，外链按钮行增加 DOUBAN，剧情简介替换为豆瓣中文。

- **ACM**：中文片名行内跟随，行内豆瓣评分，中文简介与演员 / 职员 / 关键词。

![](/assets/detail-acm.jpg)

- **PTP**：评分表格加入豆瓣票根图标，「中文简介」面板与电影信息（导演 / 类型 / 国家 / 语言 / 时长 / 又名）。

### 种子列表页：中文片名

种子列表页在每个资源的原标题下方增加豆瓣中文片名，字号、颜色、风格与原标题一致、左对齐；点击中文片名跳豆瓣条目。只处理当前页面列出的资源，翻页 / 筛选后新出现的行会自动补上。同一部作品的多个版本（不同压制 / 片源）只请求一次数据、各行列相同内容。

片名格式按资源类型区分：

- 非剧集：`宇宙巨人：希曼崛起 (2026)`
- 剧集单集：`中央情报局 第二季 第4集 (2026)`
- 剧集整季：`妄想代理人 第一季 全13集 (2004)`

- **BTN**：每个原标题下方增加豆瓣中文片名（含季集）。

## TMDB 兜底

豆瓣偶尔拿不到中文片名、剧情或海报（条目刚建好还没有中文翻译、图床把海报拦下、条目本身没有海报等），这时由 [TMDB](https://www.themoviedb.org/) 补齐。三个字段各自独立回退，互不影响：

- **中文片名**：豆瓣中文 → TMDB 中文 → 豆瓣原文 → 站点原片名
- **剧情简介**：豆瓣中文 → TMDB 中文 → 豆瓣原文 → 站点原简介
- **海报**：豆瓣 → TMDB → 站点原海报（海报回退与上面两个字段独立判断，确保尽量有图）

片名与简介按「谁有中文就用谁的」：豆瓣和 TMDB 谁有中文就用谁的数据，两者都没有中文时才用站点原有内容。TMDB 的中文按 `简体（CN）→ 香港繁体（HK）→ 台湾繁体（TW）` 依次回退，三者都没有时视为没有中文，不会拿英文顶替。

条目定位：行里带了 IMDb 编号时按编号反查（与详情页一致）；没有编号时（如 BTN 列表行）按发行名加年份检索，并做同名作品校验，避免错配。整季资源的总集数在豆瓣取不到时走 TMDB 季接口兜底。

海报回退为「豆瓣 → TMDB → 站点原海报」：直连全失败时先用站点同源海报顶着保证立刻有图，同时脚本把豆瓣 / TMDB 海报拉成 data 地址按优先级换掉；海报 `<img>` 带 `referrerpolicy="unsafe-url"` 绕过豆瓣防盗链。

跳转规则：片名链接跟随片名数据来源 —— 豆瓣片名（含豆瓣只有英文片名时）跳豆瓣条目，中文片名由 TMDB 补上时跳 TMDB 条目页；两个数据源都没有时不插入内容、不跳转，站点保持原样。豆瓣入口按钮、豆瓣评分、豆瓣卡片始终跳豆瓣。

### 申请并填写 API Key

TMDB 接口需要自己申请的凭据，在 [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api) 申请。该页有两栏，粘哪一栏都认，脚本按内容自动区分：

- **API Read Access Token（v4，推荐）**：一长串以 `eyJ` 开头的 JWT，走 `Authorization: Bearer` 头。
- **API Key (v3 auth)**：32 位十六进制，拼在 URL 的 `api_key` 参数上。

凭据只存在浏览器本地（`GM_setValue`），不随脚本源码分发，脚本内也没有内置任何 Key。**没有配置 Key 时整个 TMDB 通道静默关闭，一个 TMDB 请求都不会发出。**

填写方式按脚本管理器区分：

- **Tampermonkey / Violentmonkey / Greasemonkey / Userscripts（桌面端扩展）**：点击浏览器工具栏的脚本管理器图标 → 找到本脚本的子菜单 → 点 **设置 TMDB API Key（豆瓣兜底）** → 粘贴 Key → 确定 → 刷新页面。（也可在 Tampermonkey 管理面板选中脚本后，从顶部菜单进入同一命令。）
- **Stay / Stay for Safari（Safari 扩展）**：命令同样由 `GM_registerMenuCommand` 注册，出现在 Stay 的脚本菜单里 —— 打开 Stay App 中本脚本的条目，或在 Safari 里通过 Stay 扩展菜单找到 **设置 TMDB API Key（豆瓣兜底）**，点击后同样弹出输入框，粘贴 → 确定 → 刷新页面。

两种方式弹出的都是同一个输入框：粘贴 Key 确定即保存并提示「刷新页面后生效」；**留空并确定可清除**已保存的 Key，清除后兜底整体关闭，脚本行为与加 TMDB 之前完全一致。

## 请求与缓存约束

- **只读当前页面**：只请求页面里实际列出的资源，不预取其它页面；翻页 / 切视图后新出现的行列由 DOM 监听自动补上，数据走缓存不再发请求。
- **限流**：豆瓣请求排入同一队列依次发出（约每 0.4 秒一个、少量并发），失败退避后重试一次；TMDB 走独立约 0.1 秒闸门，429 退避重试、无效 Key 直接放弃本轮兜底。
- **缓存 30 天**：检索结果与条目详情按片名、条目编号、IMDb 编号缓存；同一片名 / 同一资源重复出现或翻页回头时不再重复请求。TMDB 没有的条目不入缓存，30 天后值得再试。
- **同一作品多版本只查一次**：按「IMDb 编号 + 片名 + 年份 + 季数 + 集数」归并，各版本共用一份结果。
- 接口请求走 `GM_xmlhttpRequest`，不受站点 CSP 与跨域限制；海报走各自图片 CDN 直连。
